# Audit UI/UX — RIMCO Studio — 26/10/2026

Audit réalisé **avant toute modification** : aucun fichier de l'application n'a été changé. Base auditée : branche `preambule`, commit `8c5bd35`.

## 1. Méthode et limites

- **Environnement.** Supabase local n'a pas pu être lancé sur ce poste (ni Docker ni CLI Supabase installés). L'audit utilise donc le mode simulation **sans Supabase** déjà prévu par le projet (`PROVIDERS_MODE=mock`, `E2E_MOCK_NO_SUPABASE=1`), dans une copie isolée du dépôt, sans `.env.local`. Aucun appel à Supabase ni à fal.ai n'a eu lieu.
- **États injectés.** Le mode simulation passe directement à « prête » et ne connaît ni file, ni décision, ni coûts. Ces états ont été simulés avec Playwright en injectant les réponses des API (`/api/versions`, `/api/versions/[id]/refresh`, `/api/storyboard/suggest`, `/api/assets`, `/api/costs`, `/api/notifications`), avec la forme exacte que produit le code serveur.
- **Rôle.** Le mode simulation impose une identité **administrateur**. La vue collaborateur (bouton « Envoyer en validation », absence des coûts réels) se déduit du code mais n'a pas été capturée. À refaire avec Supabase local.
- **Mesures automatiques** sur chaque écran : tailles de texte, contraste WCAG (seuil 4,5:1), cibles tactiles (seuil 44 px de haut), défilement horizontal.
- **Artefacts de capture à ignorer.** La pastille orange « 1 Insight » est l'indicateur de développement de Next.js : elle n'existe pas en production. Sur les captures pleine page, le menu latéral et l'en-tête fixes apparaissent parfois au milieu de l'image : c'est un effet de la capture, pas un défaut.
- **Captures** : `docs/audit-ux/NN-ecran-etat-desktop.png` (1440 px) et `…-mobile.png` (390 px).

## 3. Problèmes classés (gravité, puis effort)

Gravité : **bloquant** = empêche un usage correct ou viole une règle produit ; **gênant** = ralentit, trompe ou inquiète l'utilisateur ; **cosmétique** = finition.
Effort : **S** < ½ jour ; **M** ≈ 1 jour.

| # | Écran | Problème | Gravité | Correction proposée | Effort |
|---|---|---|---|---|---|
| 1 | Studio, file | Coût de relance affiché en dollars (« 0,15 $ ») à un collaborateur, ce qui contredit la règle « FCFA partout, prix facturé seulement » | bloquant | Afficher un montant en FCFA via `formatFcfa` (prix facturé) ou retirer le montant pour les non-admins | S |
| 2 | Global | Aucune déconnexion : « Quitter » n'a pas d'action et n'apparaît pas sur mobile | bloquant | Brancher `supabase.auth.signOut()` puis rediriger vers `/connexion` ; ajouter l'entrée au menu mobile | S |
| 3 | Bibliothèque | Statuts faux : `ready` est libellé « Validée » avant toute validation, `approved` n'a pas de libellé (affichage brut « approved »), aucun onglet « Validées » | bloquant | Libellés Prête / En validation / Validée / Refusée et onglet « Validées » | S |
| 4 | Studio | La vidéo en cours disparaît dès qu'on quitte la page, sans moyen d'y revenir | bloquant | Mettre l'identifiant de la version dans l'URL (`/?version=…`) ou en `localStorage`, puis réhydrater via `/refresh` au chargement ; ajouter un lien « Suivre dans la file » | M |
| 5 | Global | La génération s'arrête si aucun onglet Studio, File ou Bibliothèque n'est visible (webhook 503, cron quotidien) | bloquant | Court terme (S) : bandeau « Gardez cet onglet ouvert jusqu'à la fin ». Fond (M) : activer le webhook en production pour les storyboards | M |
